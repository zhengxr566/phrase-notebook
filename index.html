GitHub 同步

短句保存在你 GitHub 私有仓库里的 phrases.json。每台设备第一次打开时填一次下面的信息，之后自动同步。没网时也能用：修改先存在这台设备上，联网后自动上传。

备份 / 迁移

平时不需要手动备份：GitHub 会保留每一次修改的历史。导入会和现有数据合并，同一条短句以较新的版本为准。

触发词写法（决定长句里哪些部分会被识别）

  • thank you for：普通词组，不分大小写
  • remind*：词尾通配，可匹配 remind / reminder / reminding
  • not only ... but also：中间可以隔几个词（限同一句）
  • 每行写一条；不写时默认用标题
